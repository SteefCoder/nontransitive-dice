# nontransitive-dice

This repo contains lots of ways to find nontransitive dice. Since I was working a lot without keeping track using this github repo, I had Claude structure everything. See `CLAUDE_SUMMARY.md` for details.

The problem is also detailed in Youhua Li's github (https://github.com/YouhuaLi/Intransitive_dice), where he has a lot of work done as well.

Do not expect that most of the code here works immediately as it is all tests and proof of concepts. It is also a mix of AI-generated code and stuff I wrote myself (though I think it is easy to spot the difference).
